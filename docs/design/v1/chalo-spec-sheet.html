Duration Tokens
--duration-fast 150ms Button hover states, chip selection, focus rings
--duration-normal 250ms Screen transitions, card slides, tab switches
--duration-slow 400ms Sheet slide-up, modal appear, page-level transitions
Performance rule: Only animate transform and opacity. Never animate width, height, top, left, margin, or padding — triggers layout reflow and causes jank on Snapdragon 400-series chips common in mid-range Faridabad devices.
