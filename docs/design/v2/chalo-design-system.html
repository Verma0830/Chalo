USAGE RULE

Foundation · 05

Motion & Animation

Motion should feel purposeful, not decorative. On low-end Android devices, heavy animations can cause jank — keep transitions under 400ms and use hardware-accelerated properties only (transform, opacity). Avoid animating layout properties.

Easing Curves
ease-out
cubic-bezier(0.16, 1, 0.3, 1)
Enters, slide-up sheets, cards appearing — starts fast, lands soft
ease-spring
cubic-bezier(0.34, 1.56, 0.64, 1)
Rider found card, success states — slight bounce for delight
ease-in
cubic-bezier(0.55, 0, 1, 0.45)
Exits, dismissals — starts slow, ends fast
linear
linear
Timer countdown, progress bars, ripple animations
Duration Tokens
--duration-fast · 150ms
Button hover states, chip selection, focus rings
--duration-normal · 250ms
Screen transitions, card slides, tab switches
--duration-slow · 400ms
Sheet slide-up, modal appear, page-level transitions
PERFORMANCE RULES
Only animate transform and opacity. Never animate: width, height, top, left, margin, padding — these trigger layout reflow and cause jank on Snapdragon 400-series chips. The 60s timer countdown and ripple animations use requestAnimationFrame in the native app, not CSS transitions.
Foundation · 06

Punjabi Typography

Noto Sans Gurmukhi ensures correct Gurmukhi script rendering across all Android 9+ devices. The font is pre-bundled in the APK to avoid network dependency for script rendering.

// Android font stack in app/res/font/ punjabi_body: NotoSansGurmukhi-Regular.ttf punjabi_medium: NotoSansGurmukhi-Medium.ttf punjabi_semibold: NotoSansGurmukhi-SemiBold.ttf // Usage in XML android:fontFamily: "@font/punjabi_medium" android:lineSpacingMultiplier: "1.5" // Required for Gurmukhi // Shared Prefs for language toggle LANG_KEY: "pa" | "en" // ISO 639-1
