Edge Case States Reference
CUSTOMER EDGE CASES
🚫 No riders (3 min) → Red empty state · "Try Again" + "Schedule" CTAs
📍 GPS denied → Manual pickup entry prompt shown
↩️ Driver cancels → Auto re-search, toast: "Finding new rider"
💳 UPI failure → Retry → Switch to cash. Ride never blocked
📶 Weak signal mid-ride → Yellow banner · Cached GPS · Auto-reconnect
📅 Scheduled: no driver → 5-min window → Reschedule options
🆘 SOS: no contact saved → Prompt setup + attempts to send anyway
DRIVER EDGE CASES
⏰ 60s expires → "Request passed" toast — no penalty, no counter
📱 Backgrounded → FCM full-screen intent wakes screen-off device
📍 GPS lost mid-ride → Yellow banner · Fare unaffected · Cached position
📄 Doc rejected → Specific reason + targeted re-upload link only
👻 Customer no-show → 5-min wait → "No-Show" button appears
💸 Withdrawal failure → Balance retained · Retry available · Never lost
⚡ Offline accidentally → Confirmation dialog prevents accidental drop
