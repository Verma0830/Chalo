Edge Cases & Error States
Every unusual or failure state both apps must handle gracefully

Customer App — Edge Cases

📡 No Riders Available
After search timeout (3 min), show toast: "No riders nearby right now." Offer to retry or schedule for later. Never leave customer on a dead loading screen.
📍 GPS Not Available
Prompt to enable location. If denied, offer manual address entry for pickup location. App should not crash or block booking entirely.
❌ Customer Cancels After Accept
Confirmation dialog: "Cancel this ride?" V1: No fee, just log cancellation. Show cancellation count in profile. V2: Fee if pattern detected.
📵 Driver Cancels After Accept
Push notification to customer: "Your rider cancelled. Finding a new one." Automatically re-searches. Customer's money/booking is not lost.
💳 UPI Payment Fails
Retry option shown. If retry fails, option to switch to cash for this trip. Ride is not blocked — payment failure handled post-ride.
📶 Weak Connection Mid-Ride
Yellow banner: "Weak connection — tracking may be delayed." App caches last known position. Does not crash. Reconnects automatically.
📅 Scheduled Ride — No Driver at Time
Push at scheduled time: "Finding your rider." If no driver in 5 min, push: "No riders available right now. Rescheduling options:" — try again / cancel.
🆘 No Emergency Contact Set
If SOS tapped and no contact saved: "Set up an emergency contact first." Links to Profile > Emergency Contacts. Does not block SOS — also attempts to send to saved number.

Driver App — Edge Cases

⏱ Request Expires (60s)
Card disappears silently. Toast: "Request passed." No blame, no counter shown to driver. Back to waiting state immediately. This protects driver dignity.
📳 Missed Request (App Backgrounded)
FCM push notification with loud alert + full-screen intent. Even if driver's screen is off, notification appears. If still missed, logs as expired — not rejected.
📍 GPS Loss During Ride
Yellow banner: "Location signal lost." Last known position held. Customer tracking paused. Reconnects on signal restore. Fare is not affected.
🚫 Documents Rejected
Push: "Document update needed." Specific rejection reason shown (e.g., "License image unclear — re-upload"). Direct link to re-upload that specific document only.
💰 Dispute on Fare
V1: "Report an issue" on ride complete screen → text submission. Logged for admin review. V2: In-app dispute resolution with timeline.
📵 Customer Doesn't Show Up
Driver taps "I've Arrived." If customer doesn't board in 5 min, "Customer No-Show" button activates. Ride cancelled, logged against customer's history. Driver not penalized.
📶 Offline When Ride Request Comes
Request is sent to next available driver. Offline driver never receives stale requests. When they come back online, they see a clean state.
💸 Withdrawal Fails
Push + in-app: "Withdrawal failed — check your bank details." Link to update UPI/bank info. Balance remains in app wallet, not lost. Retry available.
